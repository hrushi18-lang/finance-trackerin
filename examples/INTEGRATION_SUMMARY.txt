3. HOW THE SYSTEM WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Example Transaction Flow:
  User enters: €30 (EUR)
  Account: USD
  Base display: INR
  
  System automatically:
    1. Fetches live EUR→USD rate from exchangerate.host
    2. Converts €30 → $33.10
    3. Fetches EUR→INR rate
    4. Converts €30 → ₹2,742
    5. Deducts $33.10 from USD account
    6. Stores all 3 amounts in database
    7. Displays ₹2,742 on dashboard

  Database stores:
    native_amount: 30
    native_currency: EUR
    converted_amount: 33.10
    converted_currency: USD
    primary_amount: 2742
    primary_currency: INR
    exchange_rate: 1.1033
    conversion_source: universal_system

4. KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Live Exchange Rates
  • API: exchangerate.host
  • Caching: 1-hour TTL (in memory + session storage)
  • Fallback: 20+ currencies with static rates
  • Manual override: For offline use

✓ 5-Case Conversion Logic
  Case 1 (T=A=B): All same - No conversion
  Case 2 (T=A≠B): Transaction=Account≠Base - Convert to base
  Case 3 (T≠A,A=B): Transaction≠Account=Base - Convert to account
  Case 4 (T=B≠A): Transaction=Base≠Account - Convert to account
  Case 5 (T≠A≠B): All different - Multi-step conversion

✓ Transaction Types
  • Income: Adds to account (positive balance change)
  • Expense: Deducts from account (negative balance change)
  • Transfer: Moves between accounts with conversion

✓ Universal Formatting
  • Uses Intl.NumberFormat
  • No hardcoded symbols
  • Works with ANY currency

✓ Automatic Caching
  • Reduces API calls
  • Session storage backup
  • Stale cache cleanup
